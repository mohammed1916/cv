CP Visualizer

Privacy Policy

Last updated: September 8, 2026

This notice explains how CP Visualizer handles information when you browse problems, use the playground, or request AI assistance.

Visitor analytics

Vercel Web Analytics is disabled on our Firebase-hosted deployment. On Vercel deployments where it is enabled, we use it to understand site traffic and improve the site. It collects page-view information such as the page URL, referring site, time, approximate location, browser, operating system, and device type. The app does not send chat messages or playground source code as analytics events.

Vercel Web Analytics does not use cookies. It derives a temporary visitor identifier from incoming requests, discards visitor sessions after 24 hours, and provides aggregate statistics. That session lifetime is not a promise that all analytics statistics are deleted after 24 hours. See Vercel's analytics privacy documentation for details.

Browser storage

The app uses local storage to remember preferences, AI provider settings, chat history, and playground code and inputs. This data remains in your browser until you delete it or clear this site's data. API keys entered in the playground's provider controls are stored in session storage, which normally lasts for the browser tab's session.

You can remove saved data using your browser's site-data settings. This also resets preferences and removes locally saved work. Close other open tabs of this site first so they do not save their current state again. These storage features support the app; they are not advertising cookies.

Optional AI features

When you request AI assistance, your messages and relevant context, which may include conversation history, problem details, visualization state, source code, inputs, or errors, are sent to the selected provider. Hosted Ollama and Google Gemini requests pass through the site's API. A key you supply for that request also passes through the API to authenticate with the provider. Local Ollama requests go directly to the configured Ollama server.

Provider processing and retention depend on the provider and account settings. See Ollama's privacy policy and Google's privacy policy. Avoid including sensitive personal information or secrets in prompts or code submitted for AI assistance. Clearing browser history does not delete information already sent to a provider.

Hosting and external resources

Hosting and API infrastructure process network requests to deliver and protect the service. Those requests include technical information such as IP addresses and request metadata and may appear in operational logs. Some editor and Python runtime resources are loaded from external content delivery networks, which also receive the network information needed to serve them. Their retention practices are separate from locally saved app data.

Your choices and questions

You can use the visualizers without requesting AI assistance and clear locally saved data through your browser. Browser privacy tools may also block analytics requests.

For privacy questions or requests, contact the maintainer through the project's GitHub repository. Do not include private information in a public issue. Depending on your location and the information involved, you may have rights to access, correct, or delete personal information or object to its processing.

We will update this page when the site's data practices change.
